# 余熱（よねつ）

商業向けを意識した **抜き特化** 成人ノベル。  
登場人物はすべて成人（みお22・せいら24・主人公24）。H差分画像は水着の全年齢代用（後差し替え）。

## 遊び方

1. `novel-studio` で「作品を開く」→ **余熱（成人向け）**
2. またはブラウザ: `npm run dev` 後に `?` なしでスタジオを開き、同メニューから選択
3. タイトル画面 → **相手を選ぶ** → 「はじめる」または「いきなりH」

直リンク（開発サーバー）:

```
http://localhost:5173/
```

作品メニューから `/yonetsu/project.json` を開く。

## 構成

| 要素 | 内容 |
|------|------|
| ヒロイン | 綾瀬みお（ホテル）／黒木せいら（バー個室） |
| ルート | 短導入 → H分岐（焦らす／欲しがるまま） |
| いきなりH | タイトル／選択画面から本編Hへ直ジャンプ |
| 回想 | 閲覧済みCGをギャラリー表示 |
